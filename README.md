## Swift

**[LazyLayoutKit](https://github.com/Dave861/LazyLayoutKit)** — Lazy custom `Layout` for SwiftUI. Declare sizes up front (an aspect ratio or a duration) instead of measuring subviews, so layout is pure arithmetic and builds nothing offscreen. 120 fps over 1,000,000 items on an iPhone 14 Pro.

**[swift-span-algorithms](https://github.com/Dave861/swift-span-algorithms)** — Algorithms for `Span` and `RawSpan`: search, comparison, trimming, chunking, windowing, splitting, cursors. No dependencies; `malloc (total) == 0` across every benchmark.

**[JudgeCalibrationKit](https://github.com/Dave861/JudgeCalibrationKit)** — Inter-rater agreement for model judges, which Apple's Evaluations framework leaves out: Cohen's κ, weighted κ, Krippendorff's α, bootstrap CIs, CI gates. Abstentions counted separately. I coordinated with Rudrank Riyam to keep the package compatible with his [Evaluations-Framework-CLI](https://github.com/rudrankriyam/Evaluations-Framework-CLI).
